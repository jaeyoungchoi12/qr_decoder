# QR Decoder

이미지를 끌어다 놓거나 첨부하면 QR 코드를 즉시 디코딩하는 웹 페이지입니다. 모든 처리는 브라우저 안에서 이루어지며, 이미지는 서버로 전송되지 않습니다.

## 기능

- **드래그 & 드롭** — QR 이미지를 화면으로 끌어다 놓으면 바로 디코딩
- **파일 첨부** — 클릭해서 이미지 파일 선택 (PNG · JPG · WEBP · GIF · SVG)
- **붙여넣기** — `Ctrl/⌘ + V` 로 클립보드 이미지 바로 디코딩
- **결과 표시** — 디코딩된 값과 함께 타입(URL·Wi-Fi·이메일·전화·텍스트 등) 자동 감지
- **복사 버튼** — 디코딩 값을 클립보드로 원클릭 복사
- **링크 열기** — URL인 경우 새 탭으로 바로 이동
- **인식 보정** — 1차 실패 시 대비 보정 후 재시도

## 실행 방법

별도 빌드 없이 `index.html` 을 브라우저로 열면 됩니다.

로컬 서버로 실행하려면:

```bash
cd qr-decoder
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음)
- [jsQR](https://github.com/cozmo/jsQR) — QR 디코딩 라이브러리 (CDN)
